# pulseschema

Pulse encode/decode helpers for schema payloads in pipelines.

**Site:** https://theworker02.github.io/pulseschema/

## Install / run

```bash
git clone https://github.com/theworker02/pulseschema.git
cd pulseschema
node src/cli.js
node --test
```
